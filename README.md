# Lance's Flight Plan — Flite Fest 2026

A one-page trip briefing built for Lance, a Japanese-language student, ahead of
Flite Fest 2026 (6–9 Aug 2026) at the National Museum of the U.S. Air Force,
Dayton, Ohio.

- Live countdown to the gates opening
- Live weather from Open-Meteo, scored for RC flyability (wind, not rain)
- Six aircraft to find, each with its Japanese word (furigana over every kanji)
- Grammar from his 23 Jul lesson, re-aimed at airplanes
- Verified nearby attractions and restaurants
- **English / やさしい日本語 toggle** — every description exists in both

No build step, no dependencies. `index.html` + `app.js` + `img/`.
